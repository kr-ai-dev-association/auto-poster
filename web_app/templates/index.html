슬라이드 타이밍 편집기

비디오 시퀀스를 확인하고 슬라이드 타이밍을 수동으로 조절하세요

🇰🇷 한국어 🇺🇸 English

💡 사용 방법:

MD 파일의 맨 위에 이미지 링크를 삽입하세요.

예: ![이미지 설명](https://example.com/image.jpg)

또는: <img src="https://example.com/image.jpg" alt="설명">

이미지삽입은 ![설명](구글드라이브링크) 형식으로 삽입하세요.

Auto Poster가 구글드라이브 이미지를 사용 가능한 URL 형태로 변환합니다.

1️⃣ 구글 드라이브에 이미지 업로드

구글 드라이브에 이미지를 업로드하고 공유 링크를 생성하세요.

2️⃣ 공유 설정

파일 우클릭 → "공유" → "링크가 있는 모든 사용자"로 설정

⚠️ 공유 설정이 없으면 이미지가 표시되지 않습니다

3️⃣ 마크다운에 삽입

마크다운 내용의 맨 위에 다음 형식으로 삽입:

![이미지 설명](https://drive.google.com/file/d/FILE_ID/view?usp=sharing)

✨ 자동 변환

구글 드라이브 공유 링크는 자동으로 직접 이미지 URL로 변환됩니다.

예: drive.google.com/file/d/... → drive.google.com/uc?export=view&id=...

💡 다른 이미지 호스팅

구글 드라이브 외에도 다음 형식의 이미지 URL을 사용할 수 있습니다:

  • 일반 이미지 URL (https://example.com/image.jpg)
  • 이미지 호스팅 서비스 (Imgur, Cloudinary 등)

⚠️ 주의사항

  • 이미지가 삭제되거나 공유 설정이 변경되면 표시되지 않을 수 있습니다
  • 더 안정적인 방법: 이미지를 다운로드하여 직접 호스팅하는 것을 권장합니다

📜 통합 가이드

  • 콘텐츠 분석: 업로드된 PDF 자료를 Gemini AI가 분석하여 최적의 메타데이터를 추출합니다.
  • 프리뷰 확인: 배포 전 AI가 생성한 제목, 상세 설명, 태그를 미리 확인하고 수정할 수 있습니다.
  • 영상 편집: 직접 업로드한 영상에 로고를 합성합니다. (Gen Video 영상은 이미 편집 완료)
  • 원클릭 업로드: 모든 준비가 완료되면 YouTube API를 통해 채널에 즉시 게시됩니다.
  • 소셜 홍보: 업로드 완료 후, AI 요약 기술을 활용해 LinkedIn에 즉시 홍보 게시물을 작성할 수 있습니다.
